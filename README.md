# IoT-Based Smart Runway Scheduling and Emergency Landing Management System for Air Traffic Control

## Overview

An IoT-based runway scheduling system developed using ESP32 and simulated in Wokwi.

The project monitors runway availability, detects incoming aircraft, and supports emergency landing prioritisation.

## Features

- Real-time runway occupancy detection
- Ultrasonic sensor-based aircraft monitoring
- OLED status display
- Emergency landing override button
- LED runway indicators
- Audible buzzer alerts
- ESP32-based embedded control

## Components Used

- ESP32 DevKit V1
- HC-SR04 Ultrasonic Sensor
- SSD1306 OLED Display
- Push Button
- LEDs
- Buzzer

## System Workflow

1. Sensor detects aircraft presence.
2. Runway status updated on OLED.
3. LEDs indicate runway availability.
4. Emergency aircraft can request immediate priority.
5. Buzzer generates alert notifications.
